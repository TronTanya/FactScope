# FactScope

Локальное приложение для разбора утверждений, оценки прозрачности источников и подготовки отчёта о проверке. Предназначено для учебной демонстрации на студенческой научной конференции.

FactScope **не** определяет истинность утверждения автоматически по стилю текста, ключевым словам или внешнему виду сайта. Показатели качества оформления источника отделены от доказательств по конкретному утверждению.

## Возможности

- Ввод одного конкретного утверждения и необязательного контекста
- Источник: вставка текста, файл `.txt` (UTF-8, до 1 МБ) или загрузка публичной веб-страницы
- Просмотр и ручная правка метаданных; отсутствующие поля показываются как «Не найдено»
- Чек-лист прозрачности источника без преобразования в «вероятность правды»
- Индикаторы внимания (клише, повторы «!!!», фразы в верхнем регистре) без ярлыка «фейк»
- Рабочая область доказательств с оценками пользователя
- Пользовательский вывод проверки с проверкой пояснения и наличия доказательств
- История в SQLite, HTML-отчёт и CSV доказательств (UTF-8 с BOM)
- Три учебных демонстрационных случая (не реальные расследования)

## Установка и запуск

Требуется Python 3.11+.

### Windows (PowerShell)

```powershell
cd "путь\к\проекту"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Если выполнение скриптов ограничено политикой PowerShell:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### macOS / Linux

```bash
cd путь/к/проекту
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Откройте адрес, который покажет Streamlit (обычно `http://localhost:8501`).

## Тесты

```bash
pytest -q
```

## Два уровня проверки (важно не смешивать)

1. **Программные проверки** (этот репозиторий): извлечение HTML-метаданных, поиск индикаторов, блокировка небезопасных URL, сохранение в SQLite, экранирование отчёта. Их прогоняет `pytest`.
2. **Возможное будущее учебное исследование**: влияет ли структурированный разбор на обоснованность выводов учащихся. Гипотеза сформулирована в приложении; **результаты опросов, точность и «улучшение навыков» в проекте не выдуманы и не приводятся**.

## Ограничения

- Нет автоматического вердикта об истинности
- Загрузка страниц не выполняет JavaScript и не обходит paywall
- Только HTTP/HTTPS, публичные адреса, лимиты размера и редиректов
- Интернет нужен только для явной загрузки URL; остальное работает офлайн
- Нет учётных записей, облачных ИИ и платных API

## Лицензия использования

Учебный демонстрационный проект. Демонстрационные кейсы вымышлены и помечены как демо.
